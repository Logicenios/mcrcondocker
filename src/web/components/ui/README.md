Shared UI primitives
====================

Button.svelte is adapted from shadcn-svelte (https://github.com/huntabyte/shadcn-svelte/blob/fe4b0ad3b8b30c6745346db008c3307b5afeabb1/docs/src/lib/registry/ui/button/button.svelte), retrieved 2026-10-30. Its MIT license ships in public/licenses/shadcn-svelte.txt. Variants use dashboard tokens in app.css. Bits UI supplies accessible dialogs and tabs; Tailwind utilities compose layout. Icon.svelte contains locally authored interface icons; game icons remain local Minecraft assets.
